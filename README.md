# Spearhead
An open source project with the goal to create a fun, modern, narrative driven, alternative to 40k

## Design Pillars

* Fun First - Make it fun so everyone WANTS to play
* Low Friction - a smaller rule-set will get people playing faster, having fun sooner, and playing more games
* Hobby Centric - Kit bashing is encouraged, the game should celebrate what people create, not restrict them to a certain world view or producer of models.
* Community Focused - The community makes the game. The community should drive the story, the factions, and the gameplay style

### Anti-Pillars

* not a paid ecosystem - factions and rules should not be locked behind expensive army books
* Not tournament focused - fairness matters, but not at the expense of stories
